============================================================
【如何使用】
============================================================

复制以下命令，按需修改括号中的值，粘贴到终端执行:

  ./compress_videos.sh \
    -i "(填入 源视频文件夹路径)" \
    -o "(填入 输出文件夹路径)" \
    -c "(填入 CRF质量值)" \
    -p "(填入 编码预设)" \
    -n "(填入 nice优先级)" \
    -f "(填入 文件匹配模式)" \
    --subdirs \

============================================================
【参数说明 - 概要】
============================================================

  参数          默认值    说明
  ─────────────────────────────────────────────────────────
  -i, --input   (必填)    视频输入牡蛎，例："./video"
  -o, --output  [输入目录]_compressed      压缩成品输出目录
  -c, --crf     22        质量值 (详见下方 CRF 说明)
  -p, --preset  slow      编码速度 (详见下方预设说明)
  -n, --nice    10        进程优先级，数字越大越不影响前台 (详见下方 nice 说明)
  -f, --filter  *.mp4     要压缩哪种文件，例: *.mp4 或 *.mov
  --subdirs               处理子目录中的文件，删除此行则不处理子目录
  --no-notify             完成后不弹出 macOS 通知，删除此行则完成后弹窗通知

============================================================
【参数说明 - CRF 值是什么？】
============================================================

  CRF (Constant Rate Factor) 控制输出视频的质量。
  数字越小 = 质量越高 = 文件越大
  数字越大 = 质量越低 = 文件越小

  CRF 值速查:
  ─────────────────────────────────────────────────────────
  18    视觉无损 — 肉眼难以区分差异
  20    极高画质 — 微小差异，适合收藏级视频
  22    高画质   — 默认值，画质与体积的平衡点
  24    中等画质 — 细节略有损失
  26    较低画质 — 明显压缩痕迹，适合预览/草稿
  28    低画质   — 明显可见质量下降

  建议: 先从 22 开始尝试，如果觉得不够清晰就降低到 18。
        每降低 2 个单位，文件大约增大 15~30%。

============================================================
【参数说明 - 编码预设是什么？】
============================================================

  预设控制编码器花多少时间去优化压缩。
  越慢 = 文件越小 + 质量越好，但耗时更长。

  预设速查 (以 1GB 1080p 视频为参考):
  ─────────────────────────────────────────────────────────
  预设          速度    每GB耗时      相对体积
  ─────────────────────────────────────────────────────────
  ultrafast     极快    ~1 分钟       最大 (基准+50%)
  superfast     很快    ~2 分钟       较大 (基准+30%)
  veryfast      快      ~4 分钟       偏大 (基准+15%)
  faster        较快    ~8 分钟       中等 (基准+8%)
  fast          中速    ~15 分钟      中等 (基准+3%)
  medium        慢      ~30 分钟      较小 (基准)
  slow          很慢    ~60 分钟      小 (节省~5%)
  slower        非常慢  ~120 分钟     很小 (节省~8%)
  veryslow      极慢    ~240 分钟     最小 (节省~10%)

  推荐:
    - 日常使用: fast 或 medium (速度与压缩的平衡)
    - 收藏/归档: slow (默认值，推荐)
    - 极致压缩: slower 或 veryslow (时间充裕时)

  注意: 以上耗时为 4核 CPU 估算，实际取决于电脑性能。
        视频内容越复杂 (运动场景)，耗时越长。

============================================================
【参数说明 - nice 优先级是什么？】
============================================================

  nice 控制进程的 CPU 优先级。
  数字越大，优先级越低，越不抢占其他程序。

  0    正常优先级 — 和其他程序平等竞争 CPU，适合过夜压缩
  10   低优先级  — 有其他程序运行时主动让出 CPU
  19   最低优先级 — 几乎不抢占 CPU，适合在正常使用电脑的同时压缩

============================================================
【一键启动】
============================================================

如果懒得配置，直接复制并执行：

  ./compress_videos.sh \
    -i "./Video" \
    -o "./Video_compressed" \
    -c 20 \
    -p slow \
    -n 10 \
    -f "*.mp4"\
    --subdirs

将待压缩文件放入该目录下的 /Video 文件夹中，
压缩结果将被存放至该目录下的文件夹 /Video_compressed .
