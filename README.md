# 视觉无损视频压缩脚本

将手机拍摄的 H.264 视频（.mp4）批量压缩为 HEVC（H.265）格式，在**肉眼无法区分画质差异**的前提下，将文件体积压缩 60~75%。

## 环境要求

- **macOS**（已测试）
- **ffmpeg**（需提前安装）
- **bc**（macOS 自带）

### 安装 ffmpeg

```bash
brew install ffmpeg
```

安装后执行 `ffmpeg -version` 确认成功。

## 快速开始

```bash
cd /path/to/compress_videos.sh所在目录
chmod +x compress_videos.sh
./compress_videos.sh
```

双击运行亦可。

## 工作流程

```
源目录 (20251227_videos/)
  ├── VID_001.mp4  ──→  压缩 →  输出目录 (20251227_videos_compressed/)
  ├── VID_002.mp4  ──→  压缩 →      ├── VID_001.mp4
  ├── VID_003.mp4  ──→  压缩 →      ├── VID_002.mp4
  └── ...                           └── VID_003.mp4
```

- **源文件不会被修改或删除**
- **已存在的输出文件自动跳过**，支持断点续传
- 执行途中随时可以 Ctrl+C 中断，重跑即可继续

## 配置说明

编辑脚本顶部的 **配置区** 即可调整行为：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `INPUT_DIR` | 视频所在目录 | 源文件目录 |
| `OUTPUT_DIR` | `_compressed` 结尾目录 | 压缩结果输出目录 |
| `CRF` | `18` | 质量参数（18~22 视觉无损，越低质量越高/体积越大） |
| `PRESET` | `veryslow` | 编码速度预设（veryslow 压缩率最高但最慢） |
| `NICE_LEVEL` | `19` | 进程优先级（19=最低，不影响日常使用） |
| `INPUT_DIR` | （通过 `-i` 指定） | 源文件目录 |
| `OUTPUT_DIR` | `源目录_compressed` | 压缩结果输出目录 |
| `CRF` | `22` | 质量参数（18~22 视觉无损，越低质量越高/体积越大） |
| `PRESET` | `slow` | 编码速度预设（越慢压缩率越高） |
| `NICE_LEVEL` | `10` | 进程优先级（10=低优先级，不影响日常使用） |
| `FILE_PATTERN` | `*.mp4` | 匹配的文件类型 |
| `BIT_DEPTH` | `auto` | 色深：`auto`=保持原色深；或指定 `8`/`10`/`12` |
| `NOTIFICATION` | `true` | 完成后是否弹出系统通知 |

### CRF 参数速查

- **CRF 18** — 视觉无损（推荐）
- **CRF 20** — 接近视觉无损，体积更小
- **CRF 22** — 高质量，轻微画质损失
- **CRF 24+** — 视觉有损

### PRESET 速度预设

压缩率从高到低：`veryslow` > `slower` > `slow` > `medium` > `fast` > `faster` > `veryfast`

- **veryslow**: 压缩率最高，速度最慢（约 3~5 倍实时时长）
- **slower**: 与 veryslow 差距不大但快约 20%
- **slow**: 推荐平衡点（约 2~3 倍实时时长）

## 运行原理

1. 扫描 `INPUT_DIR` 下所有 `*.mp4` 文件
2. 跳过 `OUTPUT_DIR` 中已存在的同名文件（断点续传）
3. 以最低系统优先级运行 ffmpeg，不影响其他操作
4. 使用 libx265 编码器 + CRF + 自动保持源文件色深
5. 音频流直接复制，不重新编码
6. 完成时弹出 macOS 通知

## FAQs

**Q: 运行一半关机了怎么办？**  
直接重新运行脚本。已经压缩成功的文件会被自动跳过，只处理未完成的。

**Q: 转码中电脑发烫/风扇狂转？**  
这是非常正常的。可以将 `nice` 配置改为 `19` 将优先级设为最低，不影响前台操作。如果还是觉得热，可以将 `PRESET` 改为 `slow` 或 `medium`。

**Q: 怎么知道跑完了？**  
默认设置下，跑完会弹出 macOS 桌面通知（右上角气泡）。

**Q: 怎么查看当前进度？**  
查看终端窗口输出即可。

**Q: 压缩后的视频能在手机上播放吗？**  
可以。脚本使用 `-tag:v hvc1` 标记，生成的 HEVC MP4 在 iPhone / Android / 电脑上均可正常播放。

**Q: 如何恢复原文件？**   
源文件始终保留在原目录未被修改。如果对结果不满意，直接删除输出目录即可。

**Q: 压缩后的视频和原来画质有区别吗？**  
CRF 18 下 HEVC 编码的 SSIM 通常在 0.99 以上，肉眼无法区分差异。但用专业工具（如 PSNR）对比仍有微小数值差异，属于绝对视觉无损。
